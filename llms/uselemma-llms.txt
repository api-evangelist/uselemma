# Lemma

## Docs

- [Delete project artifact](https://docs.uselemma.ai/api-reference/artifacts/delete-project-artifact.md): Deletes one uploaded project artifact.
- [Get learn-agent artifact version](https://docs.uselemma.ai/api-reference/artifacts/get-learn-agent-artifact-version.md): Returns the learn-agent KB content and metadata for a specific project, agent, and version.
- [Get uploaded project artifact content](https://docs.uselemma.ai/api-reference/artifacts/get-uploaded-project-artifact-content.md): Returns stored text content and metadata for one uploaded text artifact.
- [List learn-agent artifact versions](https://docs.uselemma.ai/api-reference/artifacts/list-learn-agent-artifact-versions.md): Returns learn-agent KB version metadata for a project and agent, newest first. The response omits artifact content.
- [List project artifacts](https://docs.uselemma.ai/api-reference/artifacts/list-project-artifacts.md): Returns learn-agent and uploaded artifacts for a project, scoped to the selected agent.
- [Regenerate project artifacts](https://docs.uselemma.ai/api-reference/artifacts/regenerate-project-artifacts.md): Starts the learn-agent workflow for a tenant-owned project and optional agent. Duplicate project+agent triggers within the dedupe window return the same workflow_id; clients should poll list_project_artifacts for a new latest_version or learn_agent_artifact version to observe completion.
- [Upload project artifact](https://docs.uselemma.ai/api-reference/artifacts/upload-project-artifact.md): Upload an agent-scoped .txt or .md file (text/plain or text/markdown).
- [Get issue](https://docs.uselemma.ai/api-reference/issues/get-issue.md): Get a single issue. The validation field is null when no validation row exists; when present it contains status, confidence, evidenceSummary, checkedTools, caveats, and validatedAt.
- [Get issue artifact context](https://docs.uselemma.ai/api-reference/issues/get-issue-artifact-context.md): Returns bounded learn-agent and uploaded text artifact context for validation and debugging.
- [Get issue chat context](https://docs.uselemma.ai/api-reference/issues/get-issue-chat-context.md): Returns the issue, recent occurrences, aggregate stats, and per-trace bundles (trace row + trace_stats + spans) for issue chat.
- [Get issue markdown](https://docs.uselemma.ai/api-reference/issues/get-issue-markdown.md): Build markdown for an issue.
- [Get issue metric series](https://docs.uselemma.ai/api-reference/issues/get-issue-metric-series.md): Returns zero-filled daily occurrence buckets for an issue over the last 30 days.
- [List dashboard issues](https://docs.uselemma.ai/api-reference/issues/list-dashboard-issues.md): List dashboard-ready issues for a project.
- [List issue occurrences](https://docs.uselemma.ai/api-reference/issues/list-issue-occurrences.md): List occurrences for an issue.
- [List issues](https://docs.uselemma.ai/api-reference/issues/list-issues.md): List issues for a project.
- [Set issue status](https://docs.uselemma.ai/api-reference/issues/set-issue-status.md): Update issue lifecycle status. Resolved and dismissed close the issue and append close feedback.
- [Create project](https://docs.uselemma.ai/api-reference/projects/create-project.md): Create a project for the authenticated tenant.
- [Get project](https://docs.uselemma.ai/api-reference/projects/get-project.md): Returns a single project if it belongs to the authenticated tenant.
- [Get project analytics](https://docs.uselemma.ai/api-reference/projects/get-project-analytics.md): Returns request/error/speed/token timeseries + top models for a project over a time range.
- [Get project metric event counts](https://docs.uselemma.ai/api-reference/projects/get-project-metric-event-counts.md): Returns metric event counts for a project.
- [Get project model scorecard](https://docs.uselemma.ai/api-reference/projects/get-project-model-scorecard.md): Returns per-model trace/token/speed aggregates for a project.
- [List projects](https://docs.uselemma.ai/api-reference/projects/list-projects.md): Returns projects available to the authenticated tenant.
- [Reorder projects](https://docs.uselemma.ai/api-reference/projects/reorder-projects.md): Persist project ordering for the authenticated tenant.
- [Update project](https://docs.uselemma.ai/api-reference/projects/update-project.md): Update a project for the authenticated tenant.
- [Bulk delete traces](https://docs.uselemma.ai/api-reference/traces/bulk-delete-traces.md): Delete multiple traces for a project.
- [Check per-trace ingest status](https://docs.uselemma.ai/api-reference/traces/check-per-trace-ingest-status.md): Returns enqueued (Redis index), ingested (ClickHouse traces row), ready (trace_stats), or not_found for a specific otel_trace_id.
- [Check ready traces](https://docs.uselemma.ai/api-reference/traces/check-ready-traces.md): Returns whether a project has ready traces.
- [Delete trace](https://docs.uselemma.ai/api-reference/traces/delete-trace.md): Delete a trace for a project.
- [Get agent names by trace ids](https://docs.uselemma.ai/api-reference/traces/get-agent-names-by-trace-ids.md): Returns a map of trace id to agent name (from ClickHouse trace_stats).
- [Get thread trace neighbors](https://docs.uselemma.ai/api-reference/traces/get-thread-trace-neighbors.md): Returns previous and next ready traces from the same thread.
- [Get trace](https://docs.uselemma.ai/api-reference/traces/get-trace.md): Loads a single trace with spans and stats.
- [Get trace by run id](https://docs.uselemma.ai/api-reference/traces/get-trace-by-run-id.md): Resolves a trace from an agent run id.
- [Get trace context bundle](https://docs.uselemma.ai/api-reference/traces/get-trace-context-bundle.md): Returns the trace row, trace_stats row, ordered spans, and issue occurrences for chat/agent context.
- [List dashboard traces](https://docs.uselemma.ai/api-reference/traces/list-dashboard-traces.md): Returns dashboard-ready traces for a project.
- [List thread issue summaries](https://docs.uselemma.ai/api-reference/traces/list-thread-issue-summaries.md): Batch-fetch issue extraction completion and destin issues for thread_ids (join key for eval trial_hash).
- [List thread traces](https://docs.uselemma.ai/api-reference/traces/list-thread-traces.md): Returns every ready trace in the given trace's thread, enriched and ordered oldest first. Empty for standalone traces.
- [List trace agent names](https://docs.uselemma.ai/api-reference/traces/list-trace-agent-names.md): Returns agent names seen in project traces.
- [List trace issue occurrences](https://docs.uselemma.ai/api-reference/traces/list-trace-issue-occurrences.md): Returns issue occurrence evidence linked to a ready trace.
- [List trace spans](https://docs.uselemma.ai/api-reference/traces/list-trace-spans.md): Returns spans for a ready trace.
- [List traces](https://docs.uselemma.ai/api-reference/traces/list-traces.md): Returns traces for a project.
- [Search traces](https://docs.uselemma.ai/api-reference/traces/search-traces.md): Search traces with structural and behavioral filters.
- [Semantic search traces](https://docs.uselemma.ai/api-reference/traces/semantic-search-traces.md): Search traces by semantic similarity over embedded trace summaries.
